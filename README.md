# 名曲プレーヤー (Public Domain Classical Music Player)

パブリックドメイン（著作権保護期間満了およびCC0オープン音源）のクラシック名曲を集めた、高機能かつミニマルなWeb音楽プレーヤーです。
全カテゴリに最低30曲以上（合計150曲）を網羅し、作業用BGMとして長時間シャッフル再生しても飽きない本格的なライブラリを備えています。

## 特徴

- **時代・音楽史別フィルター（全150曲・全カテゴリ30曲以上収録）**:
  - **すべて**: 全150曲
  - **バロック (1600-)**: 32曲（バッハ『G線上のアリア』『ブランデンブルク協奏曲』『ゴールドベルク変奏曲』、ヴィヴァルディ『四季（春・夏・秋・冬）』『マンドリン協奏曲』、ヘンデル『水上の音楽』『王宮の花火』『ハレルヤ』、アルビノーニ、スカルラッティなど）
  - **古典派 (1750-)**: 35曲（モーツァルト『アイネ・クライネ』『トルコ行進曲』『交響曲第25番・第40番・第41番』『きらきら星変奏曲』『フィガロの結婚序曲』『レクイエム』、ベートーヴェン『運命』『月光（全楽章）』『悲愴』『ワルトシュタイン』『エリーゼのために』、ハイドン『驚愕』『時計』『皇帝』など）
  - **ロマン派 (1820-)**: 48曲（ショパン『子犬のワルツ』『華麗なる大円舞曲』『別れの曲』『革命』『エオリアンハープ』『軍隊ポロネーズ』『ノクターン（嬰ハ短調・第2番）』『幻想即興曲』、リスト『ラ・カンパネラ』『愛の夢』『ため息』、シューベルト『アヴェ・マリア』『未完成』『セレナーデ』、チャイコフスキー『白鳥の湖』『花のワルツ』、ドヴォルザーク『新世界より』『ユーモレスク』、サラサーテ『ツィゴイネルワイゼン』など）
  - **近代・印象派 (1890-)**: 35曲（ドビュッシー『月の光』『アラベスク第1・2番』『亜麻色の髪の乙女』『夢』『沈める寺院』『美しき夕暮れ』、ラヴェル『ボレロ』『亡き王女のためのパヴァーヌ』『オンディーヌ』、サティ『ジムノペディ1〜3番』『グノシエンヌ1〜7番』、ホルスト『木星』『金星』『火星』、エルガー『威風堂々』『ニムロード』など）
  - **アンビエント**: 68曲（サティの家具の音楽、ドビュッシーの静寂ピアノ、バッハのゴールドベルク変奏曲、ショパンの夜想曲・子守歌など、**作業・読書に没入できる究極の癒やし曲を網羅**）
- **楽器別フィルター**:
  - **すべて**: 150曲
  - **🎹 ピアノ**: 84曲
  - **🎻 弦楽・管弦**: 56曲
  - **🪕 ギター・古楽器（チェンバロ・リュート・マンドリン・ハープ・オルゴール）**: 10曲
- **シャッフル再生 & 再生履歴機能**:
  - ランダム選曲（同一曲の連続再生を防止）
  - シャッフル中も「前の曲」で履歴を正確に遡るスマートバック機能
- **解説モード**:
  - 💡 「この曲、どこかで聴いたことない？」日常・CMの定番
  - 📖 作曲のウラ話
  - 👂 聴きどころ
- **完全パブリックドメイン / CC0**:
  - 作曲家の著作権満了（死後70年以上経過）
  - 演奏権・著作隣接権が明示的にCC0または米連邦政府パブリックドメインとして公開されている音源のみを使用
